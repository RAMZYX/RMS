# Miqāt Registration System (RMS)

A **Progressive Web App** implementing the **Miqāt Registration** design from
Figma. Installable, offline-capable, mobile-first. This build covers the core
registration happy path.

## Core flow

`Login → Miqaat List → Registration Detail → Add People → Review & Submit`

| Screen | What it does |
| --- | --- |
| **Login** | Gold-on-green hero, ITS ID / password inputs, Remember Me, Login. |
| **Miqaat List** | Gradient app bar + event cards with live/upcoming states and countdown tiles. |
| **Registration Detail** | Hero, official Fasal announcement (Arabic salawat), host city + relay centers, important notices, intro video, sticky "Register Now". |
| **Add People** | Family list with selection, guardian/caregiver assignment bottom sheet, ITS search, sticky confirm. |
| **Review & Submit** | Participant counts, grouped guardian/caregiver pairs, invited mehmaan, final submit. |

## Tech

- **Vite + React 18 + TypeScript**
- **vite-plugin-pwa** — web manifest, service worker, offline precache, installable
- **react-router-dom** for routing (each screen has its own URL)
- **react-icons** (Material) for iconography
- Self-hosted webfonts via **@fontsource**: Marcellus (serif display), Mulish (body), Amiri (Arabic)

## Running

```bash
npm install
npm run dev        # local dev server
npm run build      # production build (dist/) with service worker
npm run preview    # serve the production build
```

### Tooling scripts

```bash
npm run shots       # screenshot each screen (preview/*.png)
npm run prototype   # record the interactive walkthrough GIF (preview/prototype.gif)
node scripts/gen-icons.cjs   # regenerate PWA icons from the lantern emblem
```

These use the Chromium bundled with puppeteer (a devDependency).

## PWA

- `public/manifest` is generated by `vite-plugin-pwa` (name "Miqāt Registration",
  theme `#15402F`, portrait, standalone).
- Icons (`public/pwa-192.png`, `pwa-512.png`, `pwa-maskable-512.png`,
  `favicon.svg`) are the golden lantern emblem on the brand green.
- The service worker precaches the app shell + fonts for offline use.

## Design tokens & data

Colors, typography, spacing live as CSS variables in
[`src/styles.css`](src/styles.css). Mock content for the flow is in
[`src/data/mock.ts`](src/data/mock.ts).

> **Note on assets:** the original Figma raster assets (logo, hero photography,
> decorative mosque silhouettes) are not yet bundled — `www.figma.com` is blocked
> by this environment's network egress allowlist, so they can't be downloaded.
> They are reproduced with an SVG lantern emblem, gradients (exact Figma stops),
> and vector icons. Once `www.figma.com` is allowlisted, the real assets can be
> fetched and dropped into `src/assets/`.
